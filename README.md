# Vega

پنل مدیریت سرویس و اشتراک — سبک، سریع و موبایل‌محور.

این پروژه یک رابط مدیریتی است برای نگه‌داری اطلاعات سرویس‌ها، کاربران، مصرف حجم،
تاریخ انقضا، کانفیگ‌ها و لینک اشتراک؛ همراه با یک ربات تلگرام اختیاری برای
استعلام وضعیت.

---

## بخش‌ها

**کاربران** — ایجاد، ویرایش، فعال/غیرفعال‌سازی و حذف کاربر به همراه سهمیه حجم و مدت اعتبار.

**مصرف** — نمایش حجم کل، مصرف‌شده، باقی‌مانده و درصد مصرف.

**کانفیگ‌ها و اشتراک** — نمایش و کپی کانفیگ‌ها و لینک اشتراک هر کاربر.

### پروتکل‌ها

برای هر کاربر ۸ کانفیگ ساخته می‌شود:

| # | پروتکل | تعداد | مسیر |
|---|---|---|---|
| ۱–۴ | VLESS | ۴ | `/ws/{uuid}` |
| ۵–۶ | Trojan | ۲ | `/tr/{uuid}` |
| ۷–۸ | VMess | ۲ | `/vm/{uuid}` |

سمت سرور سه inbound جدا وجود دارد و nginx مسیرهای `/ws`، `/tr` و `/vm` را به
آن‌ها پروکسی می‌کند:

```
nginx :443 ──┬── /ws  → 127.0.0.1:10000  (VLESS)
             ├── /tr  → 127.0.0.1:10001  (Trojan)
             └── /vm  → 127.0.0.1:10002  (VMess)
```

رمز تروجان و شناسهٔ VMess هر دو همان UUID کاربر هستند، بنابراین آمار مصرف هر سه
پروتکل روی یک حساب جمع می‌شود.

**تنظیمات** — مدیریت اطلاعات ورود، توکن ربات و پارامترهای محیطی.

**ربات تلگرام** — استعلام وضعیت سرویس برای کاربر و گزارش کلی برای مدیر.

## ظاهر (تم)

ظاهر پروژه از یک فایل CSS مستقل تغذیه می‌شود که **بعد** از استایل داخلی هر قالب
لود می‌شود. هیچ کلاس، شناسه یا تابعی تغییر نمی‌کند.

دو اسکین آماده در `static/` هست و سوئیچ بین‌شان یک خط است:

| فایل | استایل |
|---|---|
| `theme-hud.css` | **Obsidian HUD** — سایبرپانک تاریک، براکت گوشه‌ها، گرید ماتریکسی، رادار |
| `theme.css` | **POP** — روشن، صورتی/لیمویی، استیکری |

برای تغییر، در `head` هر پنج قالب فقط مسیر را عوض کنید:

```html
<link rel="stylesheet" href="/static/theme-hud.css">
<!-- یا -->
<link rel="stylesheet" href="/static/theme.css">
```

حذف کامل این خط هم ظاهر اصلی پروژه را برمی‌گرداند.

### فونت‌ها

چهار فونت از Google Fonts در قالب‌ها لینک شده‌اند:
`Orbitron` (تیترهای HUD)، `Chakra Petch` (متن)، `JetBrains Mono` (برچسب‌ها و اعداد)،
`Vazirmatn` (فارسی). اگر سرور به اینترنت دسترسی نداشته باشد یا بخواهید کاملاً
آفلاین باشد، فونت‌های سیستم جانشین می‌شوند و چیدمان به‌هم نمی‌ریزد.

### تغییر رنگ‌ها

همهٔ رنگ‌ها بالای `theme-hud.css` تعریف شده‌اند:

```css
:root{
    --obsidian:#05070d;   /* پس‌زمینه */
    --violet:#a855f7;     /* تأکید اصلی */
    --cyan:#22d3ee;       /* تأکید دوم */
    --pink:#ec4899;
    --green:#10b981;
}
```

## منابع سیستم (CPU / RAM / Disk)

کارت **SYSTEM RESOURCES** در داشبورد، مصرف لحظه‌ای پردازنده، حافظه و دیسک را
با سه گیج حلقه‌ای نشان می‌دهد و هر ۳ ثانیه تازه می‌شود.

مقادیر **واقعی** هستند و از خود سرور خوانده می‌شوند — نه عدد ثابت:

- `GET /api/system` (نیازمند ورود) → JSON
- CPU: اختلاف شمارنده‌های `/proc/stat` بین دو فراخوانی
- RAM: `MemTotal` و `MemAvailable` از `/proc/meminfo`
- Disk: `shutil.disk_usage("/")`
- Uptime: `/proc/uptime` و Load Average: `os.getloadavg()`

هیچ پکیج اضافه‌ای لازم نیست (بدون `psutil`). اگر `/proc` در دسترس نباشد،
همان صفر نمایش داده می‌شود و بقیهٔ پنل دست‌نخورده کار می‌کند.

رنگ حلقه‌ها با مصرف عوض می‌شود: زیر ۷۵٪ رنگ خودش، بین ۷۵ تا ۹۰٪ کهربایی،
بالای ۹۰٪ قرمز.

## اجرا

### با Docker

```bash
docker build -t vega-panel .
docker run -d -p 8080:8080 \
  -e SECRET_KEY="یک-مقدار-تصادفی-بلند" \
  -e ADMIN_USER="admin" \
  -e ADMIN_PASS="یک-رمز-قوی" \
  --name vega vega-panel
```

### مستقیم

```bash
pip install -r requirements.txt
python app.py
```

## متغیرهای محیطی

| متغیر | توضیح |
|---|---|
| `SECRET_KEY` | کلید امضای نشست‌ها. حتماً مقدار تصادفی بگذارید. |
| `ADMIN_USER` | نام کاربری مدیر |
| `ADMIN_PASS` | رمز مدیر |
| `PORT` | پورت سرویس (پیش‌فرض ۸۰۸۰ در Docker) |

اگر `ADMIN_USER` و `ADMIN_PASS` تعریف نشده باشند، اطلاعات ورود از فایل
`panel_settings.json` خوانده می‌شود.

---

## نکته امنیتی

پیش از انتشار عمومی، این موارد را انجام دهید:

- مقدار `SECRET_KEY` را از حالت پیش‌فرض خارج کنید.
- رمز پیش‌فرض مدیر (`admin`) را تغییر دهید.
- سرویس را پشت یک reverse proxy با TLS قرار دهید.
